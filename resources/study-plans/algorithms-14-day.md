# Plan

1. Complexity and two pointers.
2. Sliding windows.
3. Binary search and monotonic feasibility.
4. Stack and monotonic stack.
5. Queue/deque and linked lists.
6. Tree DFS.
7. Tree/graph BFS and review.
8. Graph components and topological order.
9. Heaps and top-k/multiway merge.
10. Intervals and sweep lines.
11. Dynamic programming state design.
12. Backtracking and pruning.
13. Mixed timed retrieval; revisit incorrect invariants.
14. Run the [algorithms interview](../../interviews/algorithms/algorithms-intermediate-60.md).

Use the [patterns cheatsheet](../../cheatsheets/algorithms/big-o-and-patterns.md) only after attempting each problem. Prompts are original; canonical platform names are discovery references.
