# Focus

Senior evidence combines technical depth, cross-layer diagnosis, architecture, tradeoffs, delivery, and communication—not trivia volume.

# Schedule

- **Days 1–2:** browser rendering/networking/performance and security.
- **Days 3–4:** React performance, effects, API/component architecture, server/client boundaries.
- **Days 5–6:** state/data/cache architecture and observability/testing.
- **Day 7:** run [senior frontend interview](../../interviews/frontend/frontend-senior-75.md).
- **Days 8–10:** three frontend design scenarios from [the topic map](../../topics/system-design/frontend-system-design.md).
- **Day 11:** design systems and accessibility leadership.
- **Day 12:** algorithms and debugging communication.
- **Day 13:** behavioral stories: disagreement, incident, ambiguity, and feedback.
- **Day 14:** run [frontend system design](../../interviews/system-design/frontend-system-design-60.md); record gaps privately.
