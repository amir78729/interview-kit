# Rhythm

Each day: 20 minutes retrieval, 45–75 minutes focused work, and 15 minutes private reflection. Days 7 and 14 are interviews/recovery rather than content marathons.

# Week 1 — Models

1. Closures, scope, `this`, and modules.
2. Promises, async/await, event loop, debounce/throttle.
3. DOM, rendering, CSSOM/layout, navigation.
4. HTTP caching, cookies/storage, CORS, security.
5. Semantic HTML, forms, accessibility, CSS layout.
6. React rendering, keys, state, hooks.
7. Run [intermediate frontend interview](../../interviews/frontend/frontend-intermediate-60.md) and rest.

# Week 2 — Application

8. Effects, context, memoization, testing.
9. TypeScript narrowing, generics, unions, utility types.
10. State management and data fetching/caching.
11. Performance and observability.
12. [Frontend system design](../../topics/system-design/frontend-system-design.md).
13. Algorithms: [core patterns](../../topics/algorithms/core-patterns.md).
14. Run [mixed frontend interview](../../interviews/mixed/mixed-frontend-75.md); write a private next-cycle plan.
