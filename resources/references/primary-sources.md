# Web and Languages

- [ECMAScript specification](https://tc39.es/ecma262/)
- [WHATWG HTML](https://html.spec.whatwg.org/)
- [WHATWG Fetch](https://fetch.spec.whatwg.org/)
- [W3C Web Accessibility Initiative](https://www.w3.org/WAI/)
- [MDN Web Docs](https://developer.mozilla.org/)

# Frameworks and Tools

- [React documentation](https://react.dev/)
- [TypeScript documentation](https://www.typescriptlang.org/docs/)

# Usage

Prefer the relevant official specification or documentation for factual verification. Summarize in original words, record version/context where behavior evolves, and never cite a page that was not checked.
