# Principle

Interview evaluation should describe observed evidence, not infer personality or fabricate missing ability. A question should name competencies and observable criteria before the session.

# Qualitative Scale

- **Strong evidence:** correct, independent, nuanced, and transferable reasoning.
- **Adequate evidence:** correct core work with minor gaps or limited depth.
- **Partial evidence:** useful progress with material correctness, depth, or independence gaps.
- **Insufficient evidence:** the competency was not demonstrated; this is not proof of inability.

# Practice Loop

Attempt → capture actual response → compare with rubric → identify one gap → study → retry later. Track personal evidence only in `.personal/`.

# Fairness

Clarify assumptions, provide consistent permitted hints, distinguish communication style from content, avoid trivia unrelated to the role, and document evidence limitations.
