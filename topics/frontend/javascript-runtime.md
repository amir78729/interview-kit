# Overview

Interview-ready JavaScript knowledge combines lexical/runtime semantics with browser scheduling. Keep ECMAScript language behavior distinct from host APIs and event loops.

# Prerequisites

- Basic functions, objects, arrays, and browser scripting

# Core Concepts

Scope and closures; bindings and hoisting; call-site `this`; prototype lookup; equality/coercion; modules; promises, async functions, jobs/tasks; reachability and cleanup.
