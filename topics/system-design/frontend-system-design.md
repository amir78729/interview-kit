# Overview

Frontend system design starts with user journeys and crosses browser, client architecture, service contracts, quality, and operations. It is not merely component hierarchy.

# Core Concepts

Requirements; UX states; contracts; state and cache; rendering; performance; reliability; scale; security/privacy; accessibility; observability; testing; tradeoffs.
