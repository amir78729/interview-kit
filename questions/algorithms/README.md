# Blind-75-style core collection

This directory is a curated starter collection of common interview families, organized by pattern rather than as one giant file. Every prompt and explanation uses original wording. `canonical_reference` metadata records a familiar external name for discovery; it does not reproduce platform statements or proprietary solutions.

## Included patterns

- [Two pointers](two-pointers/) and [sliding window](sliding-window/)
- [Binary search](binary-search/)
- [Stacks](stack/) and [queues/deques](queue/)
- [Linked lists](linked-list/)
- [Trees](tree/) and [graphs](graph/) using DFS and BFS
- [Heaps](heap/) and [intervals](intervals/)
- [Dynamic programming](dynamic-programming/) and [backtracking](backtracking/)

This initial collection intentionally emphasizes representative, well-reviewed families over claiming a fixed canonical list: “Blind 75” variants differ among sources. Future additions should fill meaningful pattern gaps—such as trie, matrix, bit manipulation, and additional graph/DP variants—using the same original-description and duplicate-checking rules.

Start with the [core patterns topic map](../../topics/algorithms/core-patterns.md), then use the [algorithms interview](../../interviews/algorithms/algorithms-intermediate-60.md) for timed practice.
