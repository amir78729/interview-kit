# Content

Before coding, pick a normal case and edge cases that distinguish competing approaches. Trace the invariant, not just the final output.

# When to Use

Algorithm and debugging questions.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
