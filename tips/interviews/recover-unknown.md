# Content

State what you know, mark uncertainty, derive from fundamentals, and propose how you would verify. A precise boundary is stronger than confident invention.

# When to Use

When asked about an unfamiliar API, feature, or production detail.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
