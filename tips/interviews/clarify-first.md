# Content

Restate the goal, inputs, constraints, and success criteria before proposing a solution. Ask only questions that can change your approach, then state reasonable assumptions for unknowns.

# When to Use

At the start of algorithm, technical, debugging, and design questions.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
