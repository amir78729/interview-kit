# Content

Narrate decisions, invariants, and tradeoffs in short checkpoints. Avoid a constant stream of syntax commentary; give the interviewer evidence about how you are choosing.

# When to Use

While comparing approaches or recovering from uncertainty.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
