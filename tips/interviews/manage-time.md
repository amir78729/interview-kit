# Content

Agree on scope, announce when you are switching from exploration to implementation, and preserve time for testing or tradeoffs. If blocked, summarize evidence and request a small hint rather than silently spending the session.

# When to Use

Any timed exercise, especially multi-part questions.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
