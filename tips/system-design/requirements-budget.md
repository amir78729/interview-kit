# Content

Translate “fast,” “reliable,” and “large” into journeys, scale ranges, latency/freshness targets, and failure expectations. Label assumptions instead of inventing precision.

# When to Use

The first portion of a system-design interview.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
