# Content

For each major choice, name at least two viable options, the requirement each optimizes, the cost it introduces, and the signal that would make you reconsider.

# When to Use

When choosing rendering, storage, transport, consistency, or state models.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
