# Content

Explain a straightforward correct solution first, including complexity, then identify repeated work or structure that enables optimization. Do not code the baseline if time does not require it.

# When to Use

When the optimized pattern is not immediately clear.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
