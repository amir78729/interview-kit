# Content

State what remains true after every pointer move, loop iteration, queue operation, or recursive call. Use it to justify correctness and catch implementation drift.

# When to Use

Before writing the core loop or recursion.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
