# Content

Include sorting, heap operations, recursion depth, copied slices, output size, and language-operation costs. State whether space excludes returned output.

# When to Use

After selecting an approach and again after coding.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
