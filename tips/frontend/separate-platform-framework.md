# Content

Explain whether behavior comes from JavaScript, the browser/web standard, React, or a particular framework/version. This prevents framework conventions from becoming false universal claims.

# When to Use

Conceptual frontend answers and system design.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
