# Content

Choose semantic HTML and native controls first; then preserve name, role, state, keyboard, focus, contrast, and announcement behavior through customization.

# When to Use

Component implementation and frontend design.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
