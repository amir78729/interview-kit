# Content

Define the slow user interaction, collect representative field or trace evidence, isolate network/main-thread/rendering causes, change one bottleneck, and verify the user metric.

# When to Use

Performance diagnosis or architecture tradeoffs.

# Example

Apply the action in one or two sentences, then return to the interview task rather than over-explaining the technique.
