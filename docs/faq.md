# Frequently asked questions

## Do I need OpenCode?

No. It provides convenient commands and role instructions, but all content is ordinary Markdown.

## Is this frontend-only?

No. Frontend is the initial content emphasis. The shared schemas support any technical domain.

## Where are my answers and scores?

Under `.personal/`, never public directories. The directory is ignored by Git except for its README.

## Why no app or validation script?

The first version intentionally has no runtime, dependency, or build system. Humans and AI use documented conventions; future tools can parse the stable YAML model.

## Can I reuse a question in several interviews?

Yes. Interviews compose stable question IDs and should not duplicate the question text or answer.

## What if technical advice becomes outdated?

Update it when possible. Otherwise mark it `deprecated`, explain why, and link a replacement. Include version/context in claims that vary.

## Is the project licensed?

Not yet. `LICENSE.md` is an explicit placeholder; the owner must select a license before public publication.
