# Detailed contribution guide

## Add a question

Copy the specialized template, choose the narrowest correct path, create a stable ID, and complete every required section. Search first for conceptual duplicates. Ensure time and difficulty fit the prompt, hints are progressive, and the rubric can distinguish evidence levels.

## Add tips or cheatsheets

Tips solve a specific interview problem with an action and context. Cheatsheets are scan-first references; split a sheet only when it becomes difficult to navigate. Link related questions rather than repeating their complete answers.

## Add an interview

Use only existing question IDs, declare mandatory versus optional items, fit phase budgets inside total duration, cover stated competencies, and specify adaptation/closing rules. Do not include candidate records or copy full question answers.

## Add a domain

Create directories only when adding real content. Start with the common template; document meaningful domain-specific fields. Update relevant topic maps and docs without making the root architecture domain-specific.

## Review

Review metadata, factual accuracy, originality, terminology, links, duplicate concepts, reference quality, and privacy. AI-assisted material requires human review before `published`. Useful outdated items should be marked `deprecated`, with reason and replacement, rather than silently deleted.
