# AI workflow

AI agents begin with root `AGENTS.md`, then read the relevant template and nearby examples. They search before writing, prefer repository content over unsupported recall, preserve public/private separation, and report uncertain or environment-dependent claims.

For interviews, use the specialized interviewer agent and an existing definition. Use a real clock for timing, save user-specific records only under `.personal/`, and never fabricate answers, timestamps, references, or evaluation evidence.

For authoring, generated content begins in `draft` or `review`. An AI may propose edits and run consistency checks, but a human verifies technical claims before publication. External lookup is optional and must be explicit; offline operation should still provide a useful answer from local content.

Creation commands follow eight gates: instructions, template, examples, duplicate search, correct placement, complete drafting, validation, and privacy review.
